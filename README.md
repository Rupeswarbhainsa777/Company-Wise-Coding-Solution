## 🚀 How to Run

### Prerequisites
- Java JDK 8 or higher
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code)

### Running a Solution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rupeswarbhainsa777/Company-Wise-Coding-Solution.git
   cd Company-Wise-Coding-Solution
   ```

2. **Compile a Java file:**
   ```bash
   javac src/Talentpace/FindMinMax.java
   ```

3. **Run the compiled class:**
   ```bash
   java -cp src Talentpace.FindMinMax
   ```
